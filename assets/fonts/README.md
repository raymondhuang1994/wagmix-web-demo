# Offline fonts

Geist and Noto Sans TC, weights 400, 500, 600 and 700, licensed under SIL Open Font License 1.1.

Original fonts were retrieved from Google Fonts on 2026-11-05. The WOFF files are character subsets of the web content; outlines are unchanged. Update these subsets when adding characters outside the existing set. System fonts remain as fallbacks. `build.py` embeds them in the HTML; loading the demo does not request a font service.

- https://fonts.google.com/specimen/Geist
- https://fonts.google.com/noto/specimen/Noto+Sans+TC
